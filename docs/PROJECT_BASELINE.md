## 아직 확정되지 않은 구현 세부 사항

HWP 본문에는 기술 스택이 구체화되지 않았지만, 추가된 발표자료는 ML Kit·GPT-4o·10초 수집·변경 시 LLM 호출·비식별 결과 저장을 명시한다. 운영체제, 경고 횟수, 유예 길이, 세부 제한 단계는 구현 선택이다. 이러한 사항은 계획서에 맞춰 설계해야 하며, 계획서에서 이미 확정했다고 표현하지 않는다. 온라인 위험 예방은 기대 효과로 서술되어 있으므로 특정 탐지 기술 또는 성능 보장으로 확대하지 않는다.

시장 규모, 유료 전환율, 매출 추정, 인용 통계는 계획서의 가정·주장으로 보존한다. 이번 작업에서 외부 사실 검증이나 수치 재산정은 수행하지 않았다.

### 발표자료를 구현하는 세부 선택

- 기존 Android 권한·OCR·합의·공유 코어는 유지하며, 키워드 분석의 제품 경로를 GPT-4o 중계 구조로 교체한다. 앱 ID `kr.kidslock` 유지로 업데이트 설치와 기존 기록을 보존한다.
- 키는 서버 환경에만 둔다. HTTPS 중계 주소·기기 토큰을 설정하고 외부 텍스트 처리에 부모·자녀가 새로 동의해야 클라우드 분석한다. 원본 이미지 전송 없음. 텍스트 식별정보 제거는 최선 노력이며 완전 익명화를 보장하지 않는다.
- 앱·중계 서버는 캡처/OCR 원문을 디스크/로그에 남기지 않는다. API 사업자의 보관 정책까지 무보관이라고 단정하지 않는다. `store:false` 사용과 공급자 정책 확인이 별도로 필요하다.
- 목적과 위험은 별개 항목이다. 실패/모호함은 미확인으로 유지한다. 모델 추정을 확정적 안전 판정 또는 일방적 즉시 차단에 사용하지 않는다.
- 월간 추이와 직전 기간 비교를 위해 요약/사용 집계 최대 62일 보관으로 변경한다. 이는 발표자료의 확정 보관 기간이 아닌 구현 선택이며 동의문에 명시한다.
- 고정 관심사 어휘(개인 이름/원문 없는 분류값)로 저장하고 대화 추천은 자녀가 공유한 관심사만 사용한다.

## 승인된 모델 변경 예외 (2026-09-06)

사용자는 API 비용 문제로 무료 모델 전환을 요청했고, Gemini의 아동 대상 사용 및 무료 데이터 처리 조건을 설명한 뒤 제안한 로컬 실행 모델에 “그럼 그렇게 해봐”라고 승인했다. GPT-4o 지정에 한해 로컬 오픈 모델로 변경한다. OCR·변경 화면만 분석·원문 미저장·공동 동의·선택 공유 등 나머지 기준은 유지한다. PC에서 모델을 실행하는 경우 스마트폰 자체 온디바이스 LLM이라고 표현하지 않으며, PC 전원과 연결이 필요함을 안내한다. 기존 OpenAI/Gemini 키는 이 경로에서 사용하지 않는다.

## 승인된 디버깅 로그 예외 (2026-09-09)

사용자에게 “앱·중계 서버는 OCR 원문을 디스크나 로그에 남기지 않는다”는 기존 기준과의 충돌을 설명한 뒤, 사용자가 서버 이전 요청과 함께 “내가 아까 말한 모델 로그도 출력시켜줘”라고 다시 명시했다. 사용자가 지정한 `gina` 계정의 홈 디렉터리에서 실행되는 모델 작업기에 한해, 앱에서 식별정보를 줄인 OCR 텍스트와 모델의 목적·관심 주제·위험 가능성·확신도·고정 판단 이유를 디버깅 로그에 기록한다. 원본 이미지는 기록하지 않는다. 로그 파일은 `gina`만 읽을 수 있게 하고, 파일당 5MB·백업 3개로 순환한다. 다른 환경에서는 환경 변수로 명시적으로 켜지 않는 한 로그를 남기지 않는다.
