# 구현 및 검증 상태

작성일: 2026-09-05

## 기준과 범위

`PROJECT_BASELINE.md`의 제품 기준을 유지합니다. Android 우선, 기기 내 처리, 로컬 가족 합의는 이번 개발 버전의 구현 선택입니다. 가격·대상·공유 선택권을 변경하지 않았습니다.

이 버전은 OCR이 실제로 실행되는 로컬 Android MVP이며, 원격 가족 서비스와 상용 결제까지 완성한 버전은 아닙니다.

## 데이터 흐름

선택 앱 + 기기 잠금 해제 + 부모/자녀 수집 동의 + 분석 활성 상태일 때만 화면을 읽습니다.

1. 접근성 창에서 현재 앱을 확인합니다.
2. 민감 화면을 제외하고 접근성 텍스트를 읽습니다.
3. 텍스트가 부족하거나 OCR 우선 모드이면 해당 창을 캡처합니다.
4. 캡처를 기기 내 한국어 OCR로 처리합니다.
5. 앱 전환·동의 철회·일시정지 시 비동기 결과를 폐기합니다.
6. 화면 텍스트를 키워드 분류하고 원문은 저장하지 않습니다.
7. 분석 결과와 관측 출처를 저장하고, 자녀의 공유 선택으로 부모용 데이터를 새로 구성합니다.

## 제한 동작

- 규칙 변경은 상대의 승인을 초기화합니다. 부모와 자녀 양쪽 승인 후 활성화합니다.
- 한도 5분 전(짧은 한도는 시작 시점)에 경고합니다.
- 한도 도달 시 유예를 알리고, 알린 뒤의 전경 사용량으로 유예 시간을 보장합니다.
- 하루 한 번 초과를 기록하며, 최근 7일의 첫 초과는 제한하지 않습니다.
- 두 번째 초과는 10분, 세 번째 이상은 30분 동안 해당 앱 위에 제한 화면을 표시합니다.
- 종료 후 같은 날 반복 제한하지 않으며, 자정을 지나더라도 시작된 휴식 시간은 유지합니다.
- 분석이 꺼지거나 선택에서 제외된 앱, 동의가 완료되지 않은 규칙에는 제한하지 않습니다.

이 횟수·시간은 계획서에 없던 구현 기본값입니다. UI에서 절차를 설명하고 양쪽이 동의하도록 했습니다.

## 검증 결과

- APK 빌드 성공: Android 11 이상, target/compile SDK 36, 버전 0.1.0.
- 순수 Kotlin 단위 테스트 **10개 통과**, 실패·오류 0개.
- Android 15(API 35) 전용 에뮬레이터 테스트 **4개 통과**:
  - 별도 앱의 캔버스 화면을 접근성 스크린샷으로 받아 한국어 OCR → 학습 분류까지 실행.
  - 위 테스트에서 FLAG_SECURE 보호 화면 미기록과 동의 철회 후 미기록 확인.
  - 번들 한국어 OCR 모델 실행.
  - SQLite 요약 저장 및 공유 필터 확인.
  - 다섯 화면 시작·렌더링 확인(한 테스트에서 모든 탭 검사).
- UI 테스트의 UiAutomation 연결이 접근성 서비스에 간섭하여, 외부 화면 수집 1개와 나머지 3개를 별도 instrumentation 프로세스로 실행합니다. 재현 스크립트는 tools/device-test.ps1입니다.
- Android Lint: **오류 0개, 경고 19개**. 주로 API 호환 표기·문자열 국제화·선택적 KTX 사용·테스트 라이브러리 업데이트 안내입니다. 경고 없는 상태로 표현하지 않습니다.
- APK 실제 권한 검사: INTERNET 및 ACCESS_NETWORK_STATE 없음. 알림 권한과 내부 비공개 수신자 권한만 선언됨. 접근성은 별도 시스템 설정에서 활성화합니다.
- 기본 화면·리포트·설정 PNG를 직접 확인했습니다. 다섯 화면 PNG는 artifacts/qa에 있습니다.

설치 파일: artifacts/kidslock-0.1.0-debug.apk (디버그 서명, 약 51 MiB)

SHA-256: 0585E92A763D31FC885431BB569BE9EF41CA91E66AC80D239423DE5B5BCE04A8

검증 로그: artifacts/device-tests.txt, core/build/test-results/test, app/build/reports/lint-results-debug.html.

이는 합성 화면을 사용한 기능 검증입니다. 유튜브·숏폼 등 실제 서비스 화면의 수집률이나 분석 정확도, 실제 기기에서의 제한 오버레이·배터리·발열 성능을 검증한 결과는 아닙니다.

## 실기기에서 남은 검증

- Galaxy 등 실제 기기의 절전·재부팅·권한 해제 후 수집과 제한 동작.
- 유튜브/숏폼/브라우저/학습 앱의 접근성 텍스트·캡처 성공률.
- 보안 화면·다중 창·키보드·시스템 다이얼러 사용 중 동작.
- 화면 수집률, OCR 정확도, 목적 분류 오류, 배터리·발열 수치.
- 일반 사용자의 설치 과정, 접근성 정책 및 실제 Google Play 심사.

에뮬레이터 OCR 테스트가 통과해도 위 항목의 검증 완료를 의미하지 않습니다.
