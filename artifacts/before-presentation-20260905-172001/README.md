# 가루 Android MVP 0.2.0

창업계획서와 예선심사 발표자료를 함께 최우선 기준으로 삼는 AI 디지털 습관 동반자입니다. 앱 개발·빌드는 `C:\DaeHueProgram\kids\_lock`에서 이어갑니다.

## 발표자료에 맞춘 변경

- Google ML Kit 한국어 온디바이스 OCR → 변경된 텍스트만 HTTPS 중계 → GPT-4o 맥락 분류.
- 원본 이미지 미저장·미전송, OCR 텍스트 메모리 처리, 목적·관심사·위험 가능성의 검증된 형식만 로컬 저장.
- 부모·자녀 공동 규칙: 선택 앱 전체/앱별 시간, 학습 보호 시간대, 유해 가능성 개입 선택, 경고·유예·반복 위반 시 단계적 휴식.
- 일간·주간·월간 사용 추이, 목적별 관측 비율, 주간 관심사/전주 비교/패턴/대화 추천.
- 자녀의 선택 공유와 분류 수정, 가루 이름과 노랑·갈색 화면.

기술/제품 차이와 범위는 `docs/PRESENTATION_AUDIT.md`, 최우선 기준은 `docs/PROJECT_BASELINE.md`에 기록했습니다.

## 빌드와 검증

Windows PowerShell에서 `tools/build.ps1`을 실행합니다. JDK 17, Gradle 8.11.1, Android SDK 36은 기존 `.toolchain`을 사용합니다. Android 11(API 30) 이상. 최초 환경 설치는 `tools/bootstrap-android.ps1`.

APK: `app/build/outputs/apk/debug/app-debug.apk`. 패키지 ID `kr.kidslock`은 기존 설치 업데이트를 위해 유지하며 표시 이름은 가루입니다. SQLite v1→v2 마이그레이션으로 기록을 보존합니다.

`core` 단위 테스트와 Android Lint를 실행합니다. `server` 폴더에서 `python -m unittest -v test_relay.py`로 중계 규격·인증·오류 처리·출력 제한을 검사합니다. 기기 검증은 전용 `KidsLock_QA` 에뮬레이터에서 `tools/start-emulator.ps1` 및 `tools/device-test.ps1`을 사용합니다. 개인 휴대폰의 권한을 자동 변경하지 않습니다.

## 기기에서 사용

1. 설정에서 분석할 앱을 선택합니다. 기본은 선택 없음입니다.
2. 화면 분석 수집에 부모·자녀가 동의하고 Android 접근성을 직접 연결합니다.
3. GPT-4o 분석에는 `server/README.md`에 따라 준비한 HTTPS 서버가 필요합니다. 보호자 PIN 확인 후 서버 주소·별도 기기 연결 토큰을 설정합니다. OpenAI 키는 서버에만 둡니다.
4. 외부 텍스트 처리에 부모·자녀가 별도로 동의합니다. 기존 로컬 동의로 외부 전송을 자동 활성화하지 않습니다.
5. 선택 앱을 사용하면 약 10초마다 OCR하고, 텍스트가 달라진 경우에만 분석합니다. 서버 미연결·오류 시 가짜 목적 결과를 저장하지 않습니다. OCR만 확인하려면 설정의 이미지 OCR 확인을 사용합니다.
6. 약속에서 전체/앱별 시간과 학습 보호 시간대를 제안합니다. 양쪽 동의가 필요하며 수정 시 다시 동의합니다. 학습에 필요한 앱은 보호 시간에 쉬어 둘 대상에서 제외하세요.
7. 기록에서 분류를 수정하고, 리포트에서 공유 주제/목적/설명을 선택한 뒤 부모에게 보일 화면을 확인합니다.

## 구현 선택과 한계

화면 이미지와 OCR 원문은 저장하지 않지만 요약도 개인정보입니다. 월간 비교를 위해 최대 62일 보관하고 기록 삭제/동의 철회를 제공합니다. 식별정보 제거는 최선 노력이며 모든 이름·문장 정보를 제거한다는 보장이 아닙니다. OpenAI 측 보관은 API 계정 정책이 적용됩니다.

목적별 비율은 변화 화면의 관측 건수입니다. 시청 횟수나 목적별 실제 이용시간으로 환산하지 않습니다. 사용 추이는 접근성이 켜져 있고 선택 앱이 전경일 때만 집계하며 기기 전체 이용시간을 복원하지 않습니다. 관심사는 고정 분류 집합이며 임의의 개인 이름이나 원문을 저장하지 않습니다.

위험 가능성은 확정적 안전/위험 판정이 아닙니다. 낮은 확신은 미확인입니다. 유해 가능성 개입을 합의한 경우에도 경고·유예 후 반복 위반에 따른 휴식을 사용합니다. 현재 단계는 하루 한 번 초과, 7일 중 첫 초과 안내/두 번째 10분/이후 30분입니다. 학습 보호도 같은 절차를 적용합니다. 접근성 오버레이 제한은 시스템 강제 중지나 우회 불가 기능이 아닙니다.

현재 가족 흐름은 한 기기의 PIN 기반입니다. 별도 부모 기기 연결, 실서비스 계정/보호자 신원 확인, 결제, iOS, B2B 집계, 출시 심사는 미연결입니다. 가족 월 20,000원/자녀 추가 5,000원/1개월 체험 기준은 유지하며 개발 버전은 요금을 받지 않습니다.

실제 GPT-4o 품질·실기기 배터리·실제 서비스 화면의 수집률은 아직 검증하지 않았습니다. 중계 테스트의 합성 응답을 모델 품질 검증으로 표현하지 않습니다. 검증 기록은 `docs/IMPLEMENTATION_STATUS.md`를 확인하세요.
