# 키즈락 Android MVP

사업계획서의 합의 기반 규칙, 경고·유예·단계적 제한, 사용 맥락·관심사 분석, 자녀의 선택 공유를 구현하는 **로컬 기기 개발용 MVP**입니다.

현재 작업 위치: `C:\DaeHueProgram\kids\_lock`

## 기술 구성

- Kotlin / Android 네이티브 UI. Android 11(API 30) 이상, compile/target SDK 36.
- `AccessibilityService`: 선택한 앱의 전경 사용 관측, 화면 텍스트, 스크린샷.
- Google ML Kit 한국어 OCR 16.0.1: 번들 모델, 기기 내 실행.
- SQLite: 사용량과 분석 결과 저장. 화면 이미지와 임의의 OCR 전문은 저장하지 않습니다.
- 순수 Kotlin `core`: 목적·주제 분류, 합의·제한 상태, 공유 결과 필터링.
- 앱에 네트워크 권한이 없습니다. 계정·서버·유료 API 키 없이 동작합니다.

## 빌드

Windows PowerShell에서:

```powershell
Set-Location 'C:\DaeHueProgram\kids\_lock'
# 최초 설치. 공식 JDK/Gradle/Android SDK를 .toolchain 내부에 설치합니다.
.\tools\bootstrap-android.ps1
# 단위 테스트, APK 생성, Android Lint
.\tools\build.ps1
```

Android Studio에서도 이 폴더를 열고 JDK 17, Android SDK 36을 설정하여 빌드할 수 있습니다. Gradle 8.11.1 / Android Gradle Plugin 8.10.1 / Kotlin 2.1.20입니다.

생성 APK: `app/build/outputs/apk/debug/app-debug.apk`

```powershell
.\.toolchain\android-sdk\platform-tools\adb.exe install -r .\app\build\outputs\apk\debug\app-debug.apk
```

## 기기에서 시작하기

1. **설정 → 분석할 앱 선택**에서 수집할 앱만 선택합니다. 기본값은 아무 앱도 선택하지 않은 상태입니다.
2. **화면 분석 동의 / 시작**에서 부모와 자녀가 내용을 확인합니다.
3. Android 접근성 설정에서 **키즈락 화면 분석** 서비스를 직접 활성화합니다. Android 13 이상은 알림도 허용하면 경고를 확인하기 쉽습니다.
4. 선택한 앱을 사용합니다. 대체로 화면이 안정된 후, 최소 약 10초 간격으로 분석합니다.
5. 키즈락의 **기록**에서 관측 근거·분류를 확인하고 자녀의 설명을 추가할 수 있습니다.
6. **약속**에서 보호자 PIN으로 규칙을 제안하고 자녀가 동의해야 제한이 작동합니다.
7. **리포트**에서 공유할 목적 통계·관심 주제·설명을 선택하고, 미리보기 또는 PIN으로 부모 보기를 엽니다.

직접 설치한 APK는 기기 보안 설정에 따라 접근성이 제한될 수 있습니다. 기기의 공식 앱 정보 화면에서 설치 출처와 기능 설명을 확인한 뒤 허용해야 합니다. 앱이 권한을 자동 활성화하거나 OS 보호를 우회하지 않습니다.

### OCR만 빠르게 확인하기

설정의 **이미지로 한국어 OCR 확인**에서 직접 선택한 이미지를 읽을 수 있습니다. 실제 ML Kit를 실행하며 이 테스트 결과는 일상 기록에 넣지 않습니다. **화면 OCR 우선**을 선택하면 접근성 텍스트가 있어도 캡처 OCR 경로를 시험합니다.

## 구현 범위와 한계

- **실제 구현:** 접근성 텍스트·스크린샷 OCR, 앱 선택, 동의 철회/일시정지, 전경 사용 관측, 로컬 규칙 합의, 경고·유예·반복 제한 오버레이, 자녀 분류 수정, 최근 7일 리포트, 이전 7일 관측 주제 비교, 공유 범위 필터링, 보호자 PIN.
- **로컬 가족 흐름:** 같은 기기에서 가족이 사용하는 형태입니다. 부모의 별도 기기와 연결하는 계정·동기화·원격 인증은 아직 없습니다. PIN은 로컬 보호 장치이며, 별도의 보호자 신원 확인이나 법정대리인 동의 확인 시스템을 대신하지 않습니다.
- **분석:** 지금 분류기는 사전 키워드에 따른 설명 가능한 기준 구현입니다. 학습된 목적 추정 모델, 앱별 현재 영상/추천/댓글 영역 파서, 멀티모달 모델은 아직 없습니다. 관측된 텍스트로 사용자의 실제 의도를 보장하지 않습니다.
- **관측량:** 10초 표본과 60초 중복 억제를 사용합니다. 건수를 시청 횟수/정확한 목적별 시간으로 환산하지 않습니다. 서비스가 꺼지거나 잠긴 동안의 사용은 복원하지 않습니다.
- **제한:** 접근성 오버레이로 선택 앱의 상호작용을 막습니다. 시스템 앱 중지/삭제 방지/우회 불가 제품이 아닙니다. 접근성 권한 해제, 앱 강제 종료, 기기별 백그라운드 정책의 영향을 받습니다.
- **보호 화면:** 캡처 금지·비밀번호·민감 정보 표시 화면은 제외합니다. 보호된 화면을 우회하지 않습니다.
- **보관:** 원본 이미지/OCR 전문을 저장하지 않지만 분류·주제·사전 키워드·자녀가 작성한 설명 역시 개인정보입니다. 앱 사용 중 만료 기록을 정리하고, 분석 기록 삭제 기능을 제공합니다.
- **미연결:** iOS 앱, 원격 가족 연결, 결제, 실제 서비스용 법정대리인 확인, 앱스토어 출시 심사. 가격은 계획서의 가족 월 20,000원/자녀 추가 5,000원/1개월 무료 체험을 유지하며 이 빌드에서 요금을 받지 않습니다.
- **효과:** 과의존·그루밍·정신건강을 진단하거나 안전 여부를 판정하지 않습니다.

## 검증

`core/src/test`는 양쪽 합의, 유예, 중복 위반, 반복 단계, 자정, 전경 시간, 미확인 분류, 비공개 공유를 검사합니다.

`app/src/androidTest`는 Android 런타임에서 한국어 OCR, SQLite 요약 저장, 다섯 탭의 시작·렌더링을 검사합니다. UI 검증 PNG는 테스트 에뮬레이터의 앱 외부 전용 폴더 `files/qa`에 생성됩니다. 다른 앱의 보안 화면을 캡처하는 테스트가 아닙니다.

외부 앱 캡처 테스트에는 별도의 합성 화면 앱 `fixture`와 전용 에뮬레이터가 필요합니다. `tools/device-test.ps1`은 `KidsLock_QA` 에뮬레이터인지 확인하고 테스트 동안만 접근성 서비스를 활성화한 뒤 원래 설정으로 돌립니다. 개인 휴대폰에는 이 스크립트를 실행하지 않습니다.

```powershell
# system-images;android-35;google_apis;x86_64 와 emulator SDK 패키지가 필요합니다.
.\tools\start-emulator.ps1
.\tools\build.ps1 -Tasks ':core:test',':app:assembleDebug',':app:assembleDebugAndroidTest',':fixture:assembleDebug'
# 첫 부팅이 끝난 뒤 실행
.\tools\device-test.ps1
```

실제 검증 결과와 남은 기기별 확인 사항은 `docs/IMPLEMENTATION_STATUS.md`에 기록합니다. 사업계획서 기준은 `docs/PROJECT_BASELINE.md`를 따릅니다.
