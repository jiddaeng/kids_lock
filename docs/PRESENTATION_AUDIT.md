## 운영 연결과 정확도 검증의 경계

GPT-4o API 연동 코드는 구현했지만 실키와 운영 HTTPS 주소 없이는 실제 모델 호출 성공과 분류 정확도를 검증할 수 없다. 테스트의 합성 응답을 모델 정확도 증거로 사용하지 않는다. 서버는 한 가족/개발 환경용 독립 토큰과 메모리 요청 한도를 제공한다. 상용 다가구 서비스의 계정/토큰 발급·회수·지속형 비용 한도·보호자 인증·HTTPS 운영은 별도 배포 작업이다.

## 원문에서 확정하지 않은 구현 선택

62일 요약 보관, 고정 주제 어휘, 단일 가족 중계, 60초 실패 대기, 1일 1회 위반/7일 반복/10분·30분 휴식은 구현 선택이다. 모든 앱을 무차별 수집하지 않고 자녀가 선택한 앱만 분석한다. 학습 보호 대상은 공부할 때 쉬어 둘 앱이며, 사용 목적 추정 하나로 모든 앱을 강제 중지하지 않는다.
