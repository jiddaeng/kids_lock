# 가루 0.3.0: PC 로컬 모델 사용

사용자는 2026-09-06에 GPT-4o 대신 로컬 모델 사용을 승인했습니다.

## 실행

1. 이 PC에서 `C:\DaeHueProgram\kids\_lock\start-local-analysis.cmd`를 더블클릭합니다. 현재 사용자 계정으로 실행하세요. 연결 자격은 Windows DPAPI로 암호화되어 있습니다.
2. 휴대폰에 `artifacts/gauroo-0.3.0-debug.apk`를 업데이트 설치합니다. 기존 앱을 삭제할 필요가 없습니다.
3. 분석 서버 주소는 `https://gauroo-analysis.onrender.com`입니다. 기존 가루 서버 연결 토큰은 그대로 사용합니다. OpenAI 또는 Google AI Studio 키를 넣지 않습니다.
4. 앱 설정에서 분석할 앱·접근성 연결·화면 수집 동의를 확인합니다. **AI 맥락 분석 동의**에서 부모·자녀가 변경된 처리 경로에 다시 동의합니다. 이전 OpenAI 분석 동의는 자동으로 이어받지 않습니다.
5. 분석 시작 후 선택한 앱의 글자 있는 화면을 사용합니다. 약 10초마다 수집을 시도하며 변화한 텍스트만 모델에 보냅니다. AI 요청이 처리 중이면 중복 요청하지 않습니다. 결과가 도착하면 가루의 오늘·기록 화면이 갱신됩니다.
6. 끝낼 때 `stop-local-analysis.cmd`를 실행합니다. PC가 꺼지거나 절전·인터넷 끊김 상태이면 분석이 되지 않습니다.

## 데이터 경로

휴대폰 ML Kit OCR → HTTPS Render 중계 → 이 PC의 Qwen3 4B → 검증된 분류 요약 → 휴대폰 저장.

- LLM은 PC에서 실행됩니다. 스마트폰 안에서 LLM이 실행되는 구조는 아닙니다.
- OpenAI/Gemini API를 호출하지 않습니다. 모델 API 호출 요금이 없습니다. PC 전원·인터넷·연산 자원은 필요합니다.
- 원본 이미지는 기기 밖으로 보내지 않습니다. 식별정보 제거는 최선 노력이므로 OCR 텍스트가 완전히 익명이라고 보장하지 않습니다.
- Render는 OCR 텍스트를 전달 중 메모리에만 보관합니다. 처리 완료 또는 최대 160초 대기 만료 후 제거합니다. OCR 원문을 파일/DB/요청 로그에 저장하지 않습니다.
- PC 모델 API는 127.0.0.1에만 열립니다. 휴대폰에서 PC 포트를 직접 공개하거나 방화벽을 해제할 필요가 없습니다. PC 워커가 HTTPS로 중계에 접속합니다.
- 목적·주제·위험 가능성 요약만 최대 62일 기기에 보관합니다. 자녀의 공유 선택과 수정 기능을 유지합니다.

## 확인한 범위

- 전용 Android 15 에뮬레이터에서 합성 수학 화면을 실제 캡처·OCR하고 PC 모델 분석 결과를 저장하는 통합 검사.
- 분석 도중 앱을 바꿔도 동의가 유지된 결과를 저장하는 회귀 검사.
- 보호 화면, 동의 철회, 한국어 OCR, 요약 저장·선택 공유, 다섯 탭 UI 검사.
- 학습·과제·게임·대화의 합성 예문 4개는 기대한 목적과 일치. 해당 실측은 약 8~28초. 일반적인 분류 정확도나 모든 휴대폰 성능을 보장하는 결과가 아닙니다.
- PC가 꺼지면 앱에 로컬 분석 PC 연결 안내가 표시됩니다. Render 무료 서버의 유휴 복귀나 PC 부하로 더 오래 걸릴 수 있습니다.

## 운영 범위

현재 중계는 단일 가족 개발용이며 프로세스 하나의 메모리 큐·요청 한도를 사용합니다. 서버 재시작 시 처리 중 요청과 메모리 한도가 초기화됩니다. 다가구 상용 운영·영구 비용 한도·독립 가족 계정은 별도 구현이 필요합니다. 기존 OpenAI 배포 기록은 과거 상태이며 현재 모델 경로의 근거가 아닙니다.

원본 HWP/PDF는 변경하지 않았고 모델 변경 예외는 PROJECT_BASELINE.md에 기록했습니다.
